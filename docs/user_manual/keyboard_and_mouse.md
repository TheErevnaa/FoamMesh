Generated by `scripts/generate_gmsh_help_docs.py` from the window's shortcut table; do not edit by hand. Press **F1** in the application for the same list, where every key can be rebound (Preferences). A key you rebind is kept in your settings and a key that clashes with another command is refused.

## Mouse

The viewport uses a trackball camera.

| Action | Result |
|---|---|
| Left drag | Rotate about the rotation centre |
| Middle drag, or Shift + left drag | Pan |
| Right drag, or mouse wheel | Zoom |
| Ctrl + left drag | Spin about the view axis |
| Left click | Pick the face under the cursor |
| Ctrl + left click | Add the face to the selection |
| Shift + left click | Pick the whole volume rather than the face |
