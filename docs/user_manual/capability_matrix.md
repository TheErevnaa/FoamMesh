# What FoamMesh can and cannot do

Generated from FoamMesh's internal capability audit and from the shipped
source. The Evidence column cites the development tree's tests and audit
records, which are not part of this distribution.

Every row of that audit appears here with one of five readings:

- **Supported and qualified** — implemented, and a named gate keeps it working.
- **Implemented, unqualified** — it is written, and no gate proves it end to end. Check the result.
- **Missing** — the underlying tool has it and FoamMesh does not offer it. A follow-on package is named.
- **Deferred** — deliberately not done, with the reason.
- **Out of scope** — the tool has it and FoamMesh will not offer it. No package, no gate; the decision and its date are below.

The gates named below were run together on 6 September 2026 on this checkout: 27 test files, 392 tests, all passing. Three further candidate gates could not be collected at all, because the Qt `*_ui` modules they import are generated by `convertUi.py` and are not in the tree; no row is qualified against a test that cannot run.

67 rows: 49 supported and qualified, 13 implemented but unqualified, 3 missing, 0 deferred, 2 out of scope.
